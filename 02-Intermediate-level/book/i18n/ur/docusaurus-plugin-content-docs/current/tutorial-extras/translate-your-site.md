# روبوٹکس ڈاکیومنٹیشن کی بین الاقوامی کاری

بین الاقوامی کاری (i18n) ان روبوٹکس پروجیکٹس کے لیے ضروری ہے جو عالمی ریسرچ ٹیموں، مینوفیکچرنگ سائٹس، اور اینڈ یوزر مقامات پر پھیلے ہوئے ہیں۔ یہ گائیڈ دکھاتا ہے کہ بین الاقوامی تعاون کے لیے اپنی فزیکل AI اور ہیومنائیڈ روبوٹکس ڈاکیومنٹیشن کا ترجمہ کیسے کریں۔

## روبوٹکس ٹیموں کے لیے i18n ترتیب دیں

اپنے روبوٹکس پروجیکٹ سے متعلق متعدد لوکیلز کی سپورٹ شامل کرنے کے لیے `docusaurus.config.js` میں ترمیم کریں:

```js title="docusaurus.config.js"
export default {
  i18n: {
    defaultLocale: 'en',
    locales: ['en', 'ja', 'de', 'zh', 'fr', 'ur'],  // انگریزی، جاپانی، جرمن، چینی، فرانسیسی، اردو
    localeConfigs: {
      en: {
        label: 'English',
        direction: 'ltr',
      },
      ja: {
        label: '日本語',
        direction: 'ltr',
      },
      de: {
        label: 'Deutsch',
        direction: 'ltr',
      },
      zh: {
        label: '中文',
        direction: 'ltr',
      },
      fr: {
        label: 'Français',
        direction: 'ltr',
      },
      ur: {
        label: 'اردو',
        direction: 'rtl',
      },
    },
  },
};
```

## روبوٹکس ڈاکیومنٹیشن کا ترجمہ

روبوٹکس ڈاکیومنٹیشن کی تکنیکی نوعیت کو ترجمے کے دوران خاص توجہ کی ضرورت ہے:

### تکنیکی اصطلاحات
`docs/intro.md` کو اردو لوکیل میں کاپی اور ترجمہ کریں:

```bash
mkdir -p i18n/ur/docusaurus-plugin-content-docs/current/

cp docs/intro.md i18n/ur/docusaurus-plugin-content-docs/current/intro.md
```

### ریاضیاتی مساواتیں
ریاضیاتی نوٹیشنز تمام زبانوں میں یکساں رہتی ہیں:

```md
## فارورڈ کائنیمیٹکس مساوات

اینڈ ایفیکٹر کی پوزیشن اس طرح حساب کی جاتی ہے:

$$ \mathbf{T} = \prod_{i=1}^{n} \mathbf{A}_i(\theta_i) $$

جہاں:
- $\mathbf{T}$ ٹرانسفارمیشن میٹرکس ہے
- $\mathbf{A}_i(\theta_i)$ جوائنٹ $i$ کے لیے لنک ٹرانسفارمیشن میٹرکس ہے
- $\theta_i$ جوائنٹ $i$ کا زاویہ ہے
```

### ڈایاگرامز اور تصاویر
تصاویر اور ڈایاگرامز عام طور پر یکساں رہتے ہیں، کیپشنز پر ترجمہ لاگو ہوتا ہے:

```md
![روبوٹک آرم کنفیگریشن](/img/chap3.jpg)

*تصویر: جوائنٹ لیبلنگ کے ساتھ عام 6 ڈگری آف فریڈم مینی پولیٹر*
```

## اپنی لوکلائزڈ روبوٹکس سائٹ شروع کریں

ٹیسٹنگ کے لیے اردو لوکیل پر اپنی سائٹ شروع کریں:

```bash
npm run start -- --locale ur
```

آپ کی لوکلائزڈ روبوٹکس ڈاکیومنٹیشن [http://localhost:3000/ur/](http://localhost:3000/ur/) پر قابل رسائی ہے۔

## روبوٹکس ٹیموں کے لیے لوکیل ڈراپ ڈاؤن شامل کریں

بین الاقوامی روبوٹکس ٹیموں کے لیے زبانوں میں بغیر رکاوٹ نیویگیشن کی سہولت کے لیے، لوکیل ڈراپ ڈاؤن شامل کریں۔

`docusaurus.config.js` فائل میں ترمیم کریں:

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        {
          type: 'localeDropdown',
          position: 'right',
          dropdownItemsAfter: [
            {
              to: '/languages',
              label: 'تمام زبانیں',
            },
          ],
        },
        {
          type: 'docsVersionDropdown',
          position: 'left',
        },
      ],
    },
  },
};
```

لوکیل ڈراپ ڈاؤن اب آپ کے نیو بار میں ظاہر ہوتا ہے، جس سے بین الاقوامی روبوٹکس ٹیمیں اپنی پسندیدہ زبان میں دستاویزات تک رسائی حاصل کر سکتی ہیں۔

## اپنی لوکلائزڈ روبوٹکس ڈاکیومنٹیشن بنائیں

مخصوص لوکیل کے لیے اپنی سائٹ بنائیں:

```bash
npm run build -- --locale ur
```

یا تمام لوکیلز کو ایک ساتھ شامل کرنے کے لیے اپنی سائٹ بنائیں:

```bash
npm run build
```

آپ کی روبوٹکس ڈاکیومنٹیشن کی بین الاقوامی کاری عالمی تعاون کو فعال کرتی ہے، بین الاقوامی مینوفیکچرنگ اور تعیناتی ٹیموں کو سپورٹ کرتی ہے، اور فزیکل AI اور ہیومنائیڈ روبوٹکس کے میدان میں دنیا بھر میں تحقیقی شراکت داری کی سہولت فراہم کرتی ہے۔

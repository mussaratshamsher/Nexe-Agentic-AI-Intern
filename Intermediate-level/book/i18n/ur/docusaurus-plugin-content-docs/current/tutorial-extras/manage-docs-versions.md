# روبوٹکس پروجیکٹس کے لیے ڈاکیومنٹیشن ورژنز کا انتظام

آپ کی روبوٹکس ڈاکیومنٹیشن کا ورژننگ ترقی کی پیش رفت کو ٹریک کرنے، متعدد روبوٹ فرم ویئر ورژنز کو سپورٹ کرنے، اور تاریخی تحقیقی ریکارڈز کو برقرار رکھنے کے لیے بہت اہم ہے۔ یہ سسٹم ٹیموں کو ان کے ہیومنائیڈ روبوٹکس پلیٹ فارم کی ہر تکرار کے لیے درست دستاویزات کا حوالہ دینے کی اجازت دیتا ہے۔

## ڈاکیومنٹیشن ورژن بنانا

جب آپ اپنے روبوٹ پلیٹ فارم کا نیا ورژن جاری کریں (مثلاً فرم ویئر 2.1، کنٹرول سسٹم اپ ڈیٹ)، تو ایک متعلقہ ڈاکیومنٹیشن ورژن بنائیں:

```bash
npm run docusaurus docs:version 2.1-robot-platform
```

`docs` فولڈر کو `versioned_docs/version-2.1-robot-platform` میں کاپی کیا جاتا ہے اور `versions.json` بنایا جاتا ہے۔

آپ کی روبوٹکس ڈاکیومنٹیشن میں اب 2 ورژن ہیں:

- `2.1-robot-platform` `http://localhost:3000/docs/` پر مستحکم 2.1 پلیٹ فارم دستاویزات کے لیے
- `current` `http://localhost:3000/docs/next/` پر **آنے والی، غیر جاری شدہ خصوصیات اور بہتری** کے لیے

### روبوٹکس پروجیکٹس کے لیے ورژننگ حکمت عملی

سافٹ ویئر اور ہارڈ ویئر دونوں تبدیلیوں کی عکاسی کرنے والے سیمینٹک ورژننگ استعمال کرنے پر غور کریں:

```bash
# بڑے پلیٹ فارم اپ ڈیٹس (نئی روبوٹ جنریشن)
npm run docusaurus docs:version 3.0-humanoid-gen2

# معمولی بہتری (نئے الگورتھمز، سینسر اپ ڈیٹس)
npm run docusaurus docs:version 2.2-object-manipulation

# پیچز (بگ فکسز، کیلیبریشن اپ ڈیٹس)
npm run docusaurus docs:version 2.1.1-stability-fixes
```

## روبوٹکس ورژن ڈراپ ڈاؤن شامل کریں

مختلف روبوٹ پلیٹ فارم ورژنز میں بغیر رکاوٹ نیویگیٹ کرنے کے لیے، اپنے نیو بار میں ورژن ڈراپ ڈاؤن شامل کریں۔

`docusaurus.config.js` فائل میں ترمیم کریں:

```js title="docusaurus.config.js"
export default {
  themeConfig: {
    navbar: {
      items: [
        {
          type: 'docsVersionDropdown',
          position: 'left',
          dropdownItemsAfter: [
            {
              to: '/versions',
              label: 'تمام ورژنز',
            },
          ],
        },
        {
          to: '/blog',
          label: 'ریسرچ بلاگ',
          position: 'right',
        },
      ],
    },
  },
};
```

آپ کا ورژن ڈراپ ڈاؤن روبوٹکس ٹیموں کو ان کے مخصوص روبوٹ ورژن کے لیے دستاویزات جلدی سے تلاش کرنے میں مدد کرے گا۔

## روبوٹکس ٹیموں کے لیے ورژننگ کے بہترین طریقے

### 1. ہارڈ ویئر ریلیز کے ساتھ ہم آہنگی
```bash
# نیا ہارڈ ویئر جاری کرتے وقت
git tag robot-hardware-v2.0
npm run docusaurus docs:version v2.0-hardware-release

# موجودہ ہارڈ ویئر کے لیے نیا سافٹ ویئر جاری کرتے وقت
npm run docusaurus docs:version v2.1-software-update
```

### 2. فیچر ڈاکیومنٹیشن ٹائم لائن
```
ڈاکیومنٹیشن ٹائم لائن:
v1.0 (ابتدائی پلیٹ فارم) ──→ v1.1 (بہتر پرسیپشن) ──→ v2.0 (نیا ہارڈ ویئر)
         ↓                           ↓                              ↓
   بنیادی صلاحیتیں        بہتر سینسنگ              فزیکل ری ڈیزائن
```

:::tip

روبوٹکس پروجیکٹس کے لیے، ڈاکیومنٹیشن ورژنز کو روبوٹ فرم ویئر ریلیزز کے ساتھ ہم آہنگ کریں اور فیلڈ میں کام کرنے والے مختلف روبوٹ یونٹس کو سپورٹ کرنے کے لیے کم از کم 2-3 ورژن برقرار رکھیں۔

:::

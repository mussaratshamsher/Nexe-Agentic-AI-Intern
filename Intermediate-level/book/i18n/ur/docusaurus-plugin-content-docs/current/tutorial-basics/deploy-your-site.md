# اپنی روبوٹکس ڈاکیومنٹیشن سائٹ کی تعیناتی

اپنی روبوٹکس ڈاکیومنٹیشن سائٹ کی تعیناتی اس بات کو یقینی بناتی ہے کہ تحقیقی نتائج، تکنیکی وضاحتیں، اور نفاذ کی رہنمائی آپ کی ٹیم، تعاون کاروں، اور وسیع تر روبوٹکس کمیونٹی کے لیے قابل رسائی ہیں۔

Docusaurus ایک **سٹیٹک سائٹ جنریٹر** ہے (جسے **[Jamstack](https://jamstack.org/)** بھی کہا جاتا ہے)۔

یہ آپ کی سائٹ کو سادہ **سٹیٹک HTML، JavaScript اور CSS فائلوں** کے طور پر بناتا ہے جو مؤثر طریقے سے پیش کی جا سکتی ہیں۔

## روبوٹکس ڈاکیومنٹیشن کے لیے اپنی سائٹ بنائیں

اپنی روبوٹکس ڈاکیومنٹیشن کے ساتھ **پروڈکشن کے لیے** اپنی سائٹ بنائیں:

```bash
npm run build
```

سٹیٹک فائلیں `build` فولڈر میں تیار ہوتی ہیں، جس میں آپ کی تمام روبوٹکس ڈاکیومنٹیشن، کوڈ کی مثالیں، اور تکنیکی عکاسی شامل ہیں۔

### روبوٹکس مواد کے لیے آپٹیمائزیشن

ریاضیاتی مساواتوں اور بھاری کوڈ مثالوں والی روبوٹکس ڈاکیومنٹیشن سائٹس کے لیے، اضافی بلڈ آپٹیمائزیشنز پر غور کریں:

```bash
# اضافی آپٹیمائزیشنز کے ساتھ بلڈ کریں
npm run build -- --bundle-analyzer

# یا تعیناتی کے لیے مخصوص بیس URL کے ساتھ بلڈ کریں
BASEROUTER=/robotics-book npm run build
```

## اپنی روبوٹکس ڈاکیومنٹیشن سائٹ تعینات کریں

یہ یقینی بنانے کے لیے اپنے پروڈکشن بلڈ کو مقامی طور پر ٹیسٹ کریں کہ تمام روبوٹکس مواد درست طریقے سے رینڈر ہو:

```bash
npm run serve
```

`build` فولڈر اب [http://localhost:3000/](http://localhost:3000/) پر پیش کیا جا رہا ہے۔

### روبوٹکس پروجیکٹس کے لیے تعیناتی پلیٹ فارمز

آپ اپنی روبوٹکس ڈاکیومنٹیشن کو ان پلیٹ فارمز پر تعینات کر سکتے ہیں:

#### GitHub Pages (اوپن سورس کے لیے تجویز کردہ)

اوپن روبوٹکس ریسرچ پروجیکٹس کے لیے، GitHub Pages مفت ہوسٹنگ فراہم کرتا ہے:

```bash
# GitHub تعیناتی پیکج انسٹال کریں
npm install --save-dev gh-pages

# اپنے package.json میں شامل کریں:
# "scripts": {
#   "deploy": "docusaurus deploy"
# }

# GitHub پرسنل ایکسیس ٹوکن بنائیں اور سیٹ کریں:
# GIT_USER=<your-github-username> npm run deploy
```

### روبوٹکس ڈاکیومنٹیشن کے لیے مسلسل انٹیگریشن

اپنی روبوٹکس ڈاکیومنٹیشن میں اپ ڈیٹس کو خودکار طور پر تعینات کرنے کے لیے CI/CD سیٹ اپ کریں:

```yaml title=".github/workflows/deploy.yml"
name: GitHub Pages پر تعینات کریں

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  deploy:
    name: GitHub Pages پر تعینات کریں
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-node@v3
        with:
          node-version: 18
          cache: npm

      - name: ڈیپینڈنسیز انسٹال کریں
        run: npm ci
      - name: ویب سائٹ بلڈ کریں
        run: npm run build

      - name: GitHub Pages پر تعینات کریں
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./build
```

### تعیناتی کی تصدیق چیک لسٹ

روبوٹکس ڈاکیومنٹیشن سائٹس کے لیے، یقینی بنائیں:

- [ ] تمام ریاضیاتی فارمولے درست طریقے سے رینڈر ہوتے ہیں
- [ ] کوڈ کی مثالیں صحیح طریقے سے سنٹیکس ہائی لائٹ ہیں
- [ ] تکنیکی ڈایاگرامز اور تصاویر قابل رسائی ہیں
- [ ] روبوٹکس تصورات کے درمیان کراس ریفرنسز کام کرتے ہیں
- [ ] سرچ فنکشنیلٹی ڈومین کی مخصوص اصطلاحات ڈھونڈتی ہے
- [ ] MathJax/LaTeX مساواتیں صحیح طریقے سے ظاہر ہوتی ہیں
- [ ] انٹرایکٹو عناصر (اگر کوئی ہوں) صحیح طریقے سے کام کرتے ہیں
- [ ] فیلڈ روبوٹکس ٹیموں کے لیے موبائل دیکھنا کام کرتا ہے

اب آپ اپنی روبوٹکس ڈاکیومنٹیشن پر مشتمل `build` فولڈر کو **تقریباً کہیں بھی** آسانی سے، **مفت** یا بہت کم لاگت پر تعینات کر سکتے ہیں (مزید پڑھیں **[تعیناتی گائیڈ](https://docusaurus.io/docs/deployment)**)۔
